# Campus Connect – Sprint 5

## Project Overview

Campus Connect is a campus event platform that helps students discover and participate in events, workshops, cultural programs, sports activities, and other opportunities happening on campus.

## Sprint 5

Sprint 5 focuses on setting up the frontend structure of the Campus Connect application using React and Vite.

## Technologies Used

- React
- Vite
- JavaScript
- JSX
- CSS
- Git and GitHub
